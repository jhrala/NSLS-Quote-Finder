# NSLS Quote Finder — Conventions for Claude Code

This repo provides the `/find-quotes` and `/ingest-quotes` Claude Code commands plus the shared quote database (`quotes.json`) and ingestion scripts.

## Design Guardrail

When proposing changes that affect what users see or do, read DESIGN.md first and evaluate the change against its UX principles before proceeding.

`DESIGN.md` (repo root) captures what this tool is, who uses it, its UX principles, and what it should never become. This is a Company-wide automation — keep changes aligned with that design intent.
